# Copy frameworks & format specs

## Frameworks

**PAS — Problem, Agitate, Solve**
Problem: name the pain in their words. Agitate: what it costs them / what happens
if nothing changes. Solve: the product as the way out + CTA.

**BAB — Before, After, Bridge**
Before: their life now. After: their life with the outcome. Bridge: the product
is how they get there.

**AIDA — Attention, Interest, Desire, Action**
Hook → why it matters/how it works → benefits + proof → CTA.

**4U headlines** — Useful, Urgent, Unique, Ultra-specific. Score each headline
1–4 on each; keep the top scorers.

**FAB** — Feature → Advantage → Benefit ("so that you…").

## Hook formulas
- "Stop ___ing. Do this instead."
- "I tried ___ for [time]. Here's what happened."
- "[Number] reasons ___ (the 3rd surprised me)."
- "If you ___, you need to see this."
- "The ___ nobody tells you about ___."
- Question that names the pain: "Still ___ every morning?"
- Bold claim the source can prove: "[Stat from source]."
- Call-out: "[Audience], this one's for you."

## Long-form page section stack
1. Headline + subhead (outcome + who it's for)
2. Pain section
3. Introduce the solution / unique mechanism
4. Benefits (bullets)
5. How it works (3 steps)
6. Proof (testimonials, stats, logos)
7. Offer + what's included + price
8. Guarantee / risk reversal
9. FAQ / objections
10. Final CTA

## Platform limits (approximate — check current specs if precision matters)

| Placement | Limit / guidance |
|---|---|
| Meta ads primary text | ~125 chars shows before "See more" |
| Meta ads headline | ~27–40 chars |
| Google Search RSA headline | 30 chars each (up to 15) |
| Google Search RSA description | 90 chars each (up to 4) |
| TikTok ad text | ~100 chars; hook must land in first 3 seconds of video |
| Instagram caption | 2,200 max; first ~125 chars matter |
| X / Twitter | 280 chars |
| LinkedIn post | ~210 chars before "see more" |
| Email subject | 30–50 chars; preview text 40–90 chars |
| SMS | 160 chars per segment, include opt-out if required |
| Amazon bullet | ~200–250 chars each, 5 bullets |
| Shopify / product description | Opener 1–2 lines, 3–6 bullets |

```
PROOF (20–25s): ...
CTA (25–30s):  ...
```
