# Writing Static Image Ads

## First response (when the concept isn't already clear)

Ask exactly: "What's the core idea behind this static ad concept? Please share
details about the pain point or desire you want to address, any particular
feature or benefit you want to highlight, the emotional response you want to
evoke, any specific visual elements you're considering, and the specific action
you want viewers to take."

If the user already gave this (or a Google doc / brief covers it), skip the
question and say what you're assuming.

## Definition of success

A bold, attention-grabbing visual + a powerful headline that lets the brand
increase spend profitably and acquire new customers.

**Critical perspective:** the audience does NOT know the brand and does NOT
care about it. They only care about themselves. The ad must show the brand
understands their problems, desires and aspirations.

## Use all the material

Mine every source the user gave (Google docs, research, reviews, past winners):
product mechanism, sub-avatar pains/desires, competitor gaps, brand voice,
testimonials (exact phrases), scientific details, previous winning angles.

## Headline psychology

1. **Interrupt pattern recognition** — unexpected, intriguing, emotionally charged.
2. **Trigger emotion** — curiosity, fear, desire, surprise beat logic.
3. **Speak to deep desires** — status, security, freedom, connection.
4. **Create information gaps** — valuable info implied, not fully revealed.
5. **Promise value** — what they gain by reading on.
6. **Specific language** — concrete beats vague (see `concreteness.md`).
7. **Clarity** — if it isn't instantly understood, it fails. Clarity > clever.

## Output

Create **nine headlines**, each:
- 6–8 words max, simple, clear
- one key objective: stop the scroll of the sub-avatar
- taps one specific emotion or desire
- original to this product (use principles, not copied structures)

For each headline give:
1. **Headline**
2. **Why it stops the scroll** (1–2 lines: emotion, gap, specificity)
3. **2 alternative variations**
4. **Visual direction** — what the image shows; must match and emphasise the
   headline (problem state, dream state, or how-it-works), sub-avatar visible

Then ask whether they want subheadlines, benefit statements (short,
ingredient → felt benefit), and CTA text ("See how it works").

## Final rules

1. **Audience-first** — they don't know or care about the brand.
2. **Visual congruency** — imagery matches and emphasises the headline.
3. **Emotional impact** — make them feel understood.
4. **Clarity & simplicity** — big readable text, little of it, clear hierarchy.
5. Call out the sub-avatar. One angle per ad.
6. No guarantee on TOF/MOF statics; add a CTA.
7. Testing sets = big visual swings, not lookalikes.
8. Self-review against the Static checklist in `review-playbook.md` before delivering.
